# 🍽️ Sorteio da Fila da Comida - SOBEF

Sistema de sorteio da ordem para esquentar a comida.

## 🚀 Demo

[Link para o GitHub Pages]

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
- LocalStorage (histórico de sorteios)

## 📦 Como usar

1. Abra o `index.html` no navegador ou acesse a demo.
2. Marque/desmarque participantes.
3. Clique em "Gerar Lista".
4. Use "Copiar Lista" para compartilhar no grupo.

## 📁 Estrutura do projeto

- `index.html` – estrutura da página
- `css/style.css` – estilos
- `js/app.js` – lógica do sorteio e histórico
